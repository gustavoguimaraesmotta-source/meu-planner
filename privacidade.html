Política de Privacidade

Meu Planner · atualizada em 22 de outubro de 2026

O Meu Planner é um planner pessoal gratuito que funciona inteiramente no seu navegador. Esta página explica quais dados ele usa, onde eles ficam e como você pode apagá-los.

1. Onde seus dados ficam

Tudo o que você cadastra — compromissos, tarefas, provas, anotações, finanças, dívidas e wishlist — é salvo no armazenamento local do seu navegador (localStorage). O Meu Planner não tem servidor: nenhum dado é enviado para o dono do site ou para terceiros.

2. Sincronização opcional com o Google Drive

Se você clicar em Entrar com Google, o planner pede permissão para:

  • Pasta de dados do app no seu Google Drive (drive.appdata): uma pasta oculta e exclusiva do Meu Planner, onde é guardado um único arquivo (meu-planner.json) com os seus dados, para que o mesmo planner apareça no seu celular e no seu computador. O planner não consegue ver, abrir ou alterar nenhum outro arquivo do seu Drive.
  • Seu e-mail e nome básicos (openid, email, profile): usados apenas para mostrar com qual conta você está conectado.

Esses dados ficam na sua própria conta Google. Eles são transferidos diretamente entre o seu navegador e o Google; o dono do Meu Planner não tem acesso a eles.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com ninguém.

3. Serviços de terceiros

Apenas ao entrar com Google, o seu navegador carrega a biblioteca de login do Google (accounts.google.com) e conversa com a API do Google Drive. O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP) conforme a política do GitHub.

4. Como apagar seus dados

  • Neste aparelho: no planner, vá em Configurações → Apagar todos os dados, ou limpe os dados do site no seu navegador.
  • No Google Drive: em Configurações do Google Drive → Gerenciar apps, encontre o Meu Planner e escolha Excluir dados ocultos do app.
  • Retirar o acesso: use Sair da conta Google no planner ou remova o Meu Planner em myaccount.google.com/permissions.
